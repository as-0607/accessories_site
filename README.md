# Accessories Site 🛍️

A front-end e-commerce accessories website built using **HTML, CSS, and JavaScript**.  
The project demonstrates UI design, basic shopping flow pages, and client-side interactions.

## 📌 Features
- Home page with products display
- Shopping cart page
- Login & Register pages
- Responsive layout
- Organized assets (CSS, JS, images, fonts)

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
